# mooncci 电量管理 v5

本版整理后台水电监控设置：顶部查看当前电量与手动操作；运行计划、通知与阈值并排，手机上顺序排列；底部显示紧凑的凭据与任务状态。保留黑白主题、全部原有操作和权限，时间按 Asia/Shanghai 显示。

## 运行计划

一行一个整点时间，支持添加、修改执行任务、删除非零点计划。00:00 固定为日统计与学校历史同步；其他行选择仅采集、采集并生成早报、采集并生成晚报。早报、晚报各最多一次，早报时间必须早于晚报，不允许重复时间。首次沿用 ELECTRICITY_SCHEDULE_HOURS（未配置为 00:00 / 07:00 / 12:00 / 21:00），不会因升级更改已使用的时间。

点击保存后写入原有 site_settings 的 electricity JSON，无新表或迁移。保存的计划优先于旧环境变量；worker 每 30 秒只读取数据库设置，并在执行前重新核对计划。无需为了后续编辑时间重启 PM2。保存不补发过去的报告。早晚报告原有快照、邮件和独立 RSS 逻辑保持；额外采集行不会改变早晚报的角色。

学校历史自动同步仍只在零点执行；白天不自动导入历史。顶部“同步学校历史用电”只补入最近 7 个完整日的学校明细，至少间隔 15 分钟，沿用服务端宿舍范围、站长权限、任务锁、持久冷却和学校限流暂停机制。不会改写零点预测、生成邮件或 RSS 条目，操作时保留表单草稿。

## 部署

适用于已安装电量 RSS 与 202609070001 日用电迁移的现有服务器；无需新增依赖、环境变量或数据库迁移。可直接覆盖 v3 / v4。

Windows PowerShell 上传本次已构建的包：

```powershell
Set-Location 'C:\Users\Administrator\Documents\mooncci site'
scp .cache/mooncci-electricity-history-sync-20260909-v5.tar.gz root@182.92.179.81:/root/
```

服务器 root SSH：

```bash
mkdir -p /root/mooncci-electricity-history-sync-20260909-v5
tar -xzf /root/mooncci-electricity-history-sync-20260909-v5.tar.gz -C /root/mooncci-electricity-history-sync-20260909-v5
bash /root/mooncci-electricity-history-sync-20260909-v5/deploy-electricity-history-sync.sh
```

脚本校验包内容、API 和 worker 的运行目录；备份修改的源码和原前端入口；安装源码后重启 mooncci-api 与 mooncci-worker，健康检查通过再发布前端。安装失败自动恢复源码与原入口。不会在部署脚本中额外请求学校历史。备份路径会在终端输出。

入口：后台 → 水电监控设置。默认计划保持 00:00 日统计、07:00 早报、12:00 仅采集、21:00 晚报；未编辑时保持这些行为。后续修改统一点击“保存设置”。测试邮件使用已保存的通知收件人。
