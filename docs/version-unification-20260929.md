# 版本统一与性能收尾 · 2026-09-29

## 版本来源与合并条件

基于 PR #50 的 `92ee8bebe2b82fd284e77a849bb9a1a98f875356` 整理。前端保留原设计；后端候选按本地源码、历史离线包和已有提交比对，未包含 .env、私钥、上传文件或运行时数据。

历史包匹配只能证明文件曾打包，不能确认服务器正在运行该版本。线上文件及 schema_migrations 校验返回前，候选保持草稿，不执行生产迁移，不发布后端包，不合并到 main。worker.js 和 runtimeStatus.js 的当前内容来自本地提交 696db56，未找到匹配的历史离线包，单独待核对。其余运行时代码差异均找到匹配的历史包。

发布流程、账号互动、邮件订阅三组源码在独立 GitHub 副本中配套验证。数据库 schema 与迁移文件仅同步源码；已有服务器不能运行 init-db，也不能重新执行历史迁移。没有证据的差异保留为待核对，不擅自标记废弃或删除。

## 性能证据与边界

问题图片为真实 WebP（RIFF/WEBP 文件头），43662 字节。当前电脑经公开域名与直接指定国内源站 IP 各测 30 次，均为 200；完整请求中位数分别约 0.148 秒和 0.150 秒。响应 Cache-Control 为 public,max-age=0，提供 ETag；本轮条件请求仍返回 200，未观察到 304，因此不能宣称缓存命中。首页另测 30 次成功。

这些结果只代表当前客户端，不代表海外用户或海外网关回源。不得据此变更线路或为所有图片添加 immutable。原图保留；本轮不修改上传转换、静态缓存、Nginx 或 DNS。后续使用 scripts/measure-access.py 在两台服务器分别采样，并记录探测位置、状态码、连接/TLS/首字节/总耗时、大小及缓存头。
