# 网站与后台体验统一 · 2026-10-23

## 实施范围

以 f8490d2 为发布基线，沿用原主题、组件和权限；没有新增依赖、后端接口或数据库迁移。

1. 后台基础：导航及概览采用语义图标；后台范围内统一44px导航/操作点击区域、标题换行、分页反馈和安全区。原有菜单分组与权限未改。
2. 内容管理：文章/媒体/动态/作品/审核/排期列表的筛选与分页保存在URL；失败可重试，旧请求不能覆盖新筛选。专栏取消和离开保护未保存编辑。既有文章编辑器草稿恢复、冲突处理、上传和发布流程继续复用。
3. 阅读发现：搜索/分类/标签原有URL状态保留；补齐非法及越界页码，长标题、目录和推荐文本按局部样式换行。保留收藏、阅读设置、媒体与代码滚动。
4. 用户邮件：用户/评论筛选和页码恢复；用户列表复用AdminState；邮箱申请区分错误与空列表并忽略旧响应；站点通知保护未发送输入，不改变发送逻辑。
5. 网站系统：AI/登录/节点/电量设置增加快照放弃和离开提醒；邮件/网站设置复用快照增加放弃。电量房间内部切换确认、保存时禁止切换；运行页明确标记刷新失败后的旧数据。平板网站设置表单单列，媒体及保存按钮不换行。

## 保留与覆盖边界

关于与友链、公共About动画、现有标签和媒体选择器不重写。评论/违禁词/编辑申请已有公共反馈；订阅/周报和监控业务保持原有流程。IndexNow沿用现有入队、回执、过期提示，未新增收录查询或保证收录。测试不向真实用户发信。

## 验收入口

- `npm run check`：类型、前端测试、构建、现有包体预算。
- `scripts/test-admin-workspace-browser.cjs`：五种宽度×深浅主题、菜单点击区、语义图标和手机菜单Escape。
- `scripts/test-content-admin-browser.cjs`：列表URL刷新/返回、筛选重置、读取重试、专栏取消保护、旧发布队列响应。
- `scripts/test-content-discovery-browser.cjs`：分页边界、搜索分类标签恢复、失败与空结果、五种宽度深浅阅读布局和目录。
- `scripts/test-admin-settings-browser.cjs`：五个代表设置页×五种宽度×深浅主题、保存失败保留、放弃和按钮不换行。
- `test/admin-settings-state.test.cjs`：快照恢复、保存成功/失败、空登录方式、电量切换保护；原媒体/编辑行为测试继续运行。
- `scripts/test-about-browser.cjs` 和 `scripts/test-loading-browser.cjs`：已有About与加载样式回归。

浏览器数据为隔离夹具；桌面Edge模拟触控不等于真实手机验收。生产发布另行核验构建摘要、CI与安装结果，不能以本文替代部署证据。

## 发布

保持五批独立提交，最终集成修正单独提交。只发布国内主服务器；本地构建dist和配对SSR离线包，无服务器安装依赖或前端构建。SSR更新需单独reload API，worker不变。保护配置、历史SQL、上传，保留备份与回滚命令。
